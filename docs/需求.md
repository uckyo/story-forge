StoryForge 网络小说大纲工具 - 用户需求文档

1. 核心功能需求

1.1 卡片系统

必须支持的卡片类型：
• 人物卡片（角色信息）

• 势力卡片（组织/团体）

• 地点卡片（场景/世界）

• 剧情点卡片（故事事件）

• 关键事件卡片（重要转折点）

卡片基本功能：
• 创建/编辑/删除卡片

• 卡片分类管理

• 卡片颜色标记

• 标签系统

• 搜索和筛选

1.2 时间线系统

核心特性：
• 垂直布局的时间线

• 时间线作为主界面

• 支持相对时间（无具体日期）

• 所有卡片可拖拽到时间线

• 拖拽调整顺序和位置

剧情点特殊要求：
• 剧情点可以嵌套（父子关系）

• 支持展开/折叠嵌套内容

• 剧情点可在时间线上直接创建

1.3 智能关联系统

@提及功能：
• 输入@符号触发选择框

• 选择框显示所有可用卡片

• 按卡片类型分类显示

• 支持实时搜索筛选

• 插入格式：【卡片名】

• 不同类型卡片显示不同颜色

悬停预览：
• 鼠标悬停在【卡片名】上显示卡片概要

• 预览信息包含核心属性

• 点击可快速编辑卡片

关系管理：
• 自动记录卡片间关联

• 双向链接关系

• 关系可视化展示

2.2 视图要求

• 时间线作为默认主页视图

• 左侧边栏可折叠/展开

• 响应式设计（支持平板）

• 暗色/亮色主题切换

3. 交互需求

3.1 拖拽操作

• 从侧边栏拖拽卡片到时间线

• 在时间线上拖拽调整卡片顺序

• 拖拽建立嵌套关系（父子剧情点）

• 拖拽改变时间位置

3.2 键盘快捷键

• 快速创建卡片（Ctrl+N）

• 快速保存（Ctrl+S）

• 快速搜索（Ctrl+F）

• 撤销/重做（Ctrl+Z/Y）

3.3 上下文操作

• 右键菜单：编辑、删除、复制卡片

• 双击卡片快速编辑

• 拖拽手柄明确标识

4. 数据管理需求

4.1 本地存储

• 浏览器本地存储所有数据

• 自动保存功能

• 手动导出/导入项目

• 数据备份机制

4.2 文件格式

• 导出为JSON格式

• 支持Markdown导出

• 项目文件可移植

5. 高级功能需求

5.1 故事结构管理

• 章节分组功能

• 故事弧光划分

• 进度追踪

• 字数统计

5.2 可视化辅助

• 关系图谱视图

• 人物关系网

• 势力分布图

• 故事节奏分析

5.3 写作辅助

• 灵感笔记功能

• 参考资料管理

• 写作目标设定

• 进度提醒

6. 用户体验需求

6.1 性能要求

• 加载速度快

• 操作响应及时

• 支持大量卡片（1000+）

• 流畅的动画效果

6.2 易用性要求

• 界面直观易懂

• 操作流程简单

• 良好的引导提示

• 详细的帮助文档

6.3 无障碍要求

• 清晰的视觉层次

• 足够的对比度

• 键盘导航支持

• 屏幕阅读器友好

7. 非功能性需求

7.1 兼容性

• 支持主流现代浏览器

• 移动端基本功能可用

• 离线工作能力

7.2 可靠性

• 数据丢失保护

• 错误恢复机制

• 操作确认提示

8. 优先级划分

P0 - 核心功能（必须实现）

• 基本卡片创建和管理

• 垂直时间线布局

• 卡片拖拽功能

• @提及系统

• 本地数据存储

P1 - 重要功能（应该实现）

• 剧情点嵌套

• 关系可视化

• 导入导出功能

• 搜索和筛选

• 撤销重做

P2 - 增强功能（可以后续实现）

• 高级分析统计

• 多项目管理

• 协作功能

• 模板系统

• 插件扩展
